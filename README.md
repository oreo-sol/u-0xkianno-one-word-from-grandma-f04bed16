# One Word From Grandma

The single word a grandma would text about AI (5 characters): the
typo she would actually make, in accidental caps lock — ROBUT.

> ROBUT

## Files

- `entry.txt` — the word, written by `main.ts` (not stored in the repo)
- `main.ts` — writes the entry word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
  (or `/output/entry.txt`), validating it is exactly one word and
  1–30 Unicode code points, then reads it back and verifies it
- `LICENSE` — MIT

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
